## ✨ 特性一览

### 🎛 复古机身
- 木质质感机身 + 顶部提手，圆角、内阴影、环境光晕一体成型
- **VU 电平表**：SVG 矢量刻度（-20 ‖ -10 · -7 · -5 · -3 -2 -1 0 +1 +2 +3 · +5），指针由音频**时域采样**计算电平驱动，带 PEAK 峰值保持
- **实时频谱**：Canvas 绘制的频域柱状图，按 `devicePixelRatio` 重建位图，高分屏不糊
- **卡带仓**：播放时双卷盘转动、计数器走字（100 → 0），点击仓门 = 播放 / 暂停
- **墨水屏时钟** + **调谐刻度窗**（FM 88 – 108 MHz 指针 + 台名 / 状态显示）
- TUNING 旋钮（打开电台列表）、VOL 旋钮（点击静音）与音量滑杆

### 📻 播放内核
- **HLS 直播**：内联 hls.js 1.5.17（MSE）；Safari / iOS 走原生 HLS
- **直连流**：`.mp3` / `.aac` 等原生音频直接交给 `<audio>`
- **多源自动回退**：一个电台可配 N 个候选源，失败自动换下一个，全挂才显示 `NO SIGNAL`
- **断流健康监听**：播放中监听卡顿 / 错误，自动切源恢复
- **连通记忆**：上次跑通的源会被记到队首并持久化，下次开台直接命中

### 📋 频谱表 v1（本机电台簿）
- 电台源用**纯文本**维护，一行一台、缩进两格写多个候选源，读改都靠肉眼
- 支持分组、`频率：`、`别名：`、单行式 `台名|源1|源2`、符号简写 `@频率` `=别名` `#分组` `//注释`
- 面板内置编辑器：**应用 / 整理格式 / 静默测源 / 导入 .txt / 导出 .txt / 清空**，并常驻一份写法说明
- 编辑器支持 `Tab` 缩进、`Esc` 收起

### 🔎 自动搜台
- 并发 6 路探测、单源 5 秒超时、整轮 25 秒总时限，不会一直转圈
- 两级判定：先 `fetch` 预检（HLS 校验 `#EXTM3U`），失败再用**静音实播**兜底（全程 `muted`，一声不出）
- 扫描顺序：上次连通的 → 本地台 → 国家级 → 其余；坏源在本次会话内屏蔽，刷新即解禁
- 命中结果缓存 7 天，下次打开秒连

### 📡 FM 自动频率追踪
打开 VU 表右上角的拨动开关，调谐指针会自动指向该台的真实 FM 频率。取值优先级：

| 顺序 | 来源 | 精度 |
| --- | --- | --- |
| 0 | 频谱表里手写的 `频率：` | 精确 |
| 1 | 台名自带的数字（103.9 / 971 → 97.1） | 精确 |
| 2 | 内置城市频率对照表（含音乐之声全国城市表） | 精确 |
| 3 | Radio Browser 联网查询 | 精确 |
| 4 | 按台名哈希估算 | 估算（显示 `≈`） |

城市由浏览器 Geolocation + OpenStreetMap Nominatim 反查得到，失败回落到默认城市。
频率映射区间 87.0 – 108.0 MHz，指针活动范围锁定在刻度盘 20% – 80%。

### 🎨 五套皮肤
`复古原木` · `深夜黑胶` · `奶油薄荷` · `红木书架` · `电竞霓虹`，选择结果写入本地存储，刷新保留。

### 🖥 全屏与高分屏
- 基于 **FLIP + Web Animations API** 的缩放过渡：全程操作真实 DOM，文字按矢量清晰度渲染，不会"先糊后清"
- 16:9 视口充分铺满，机身等比放大并居中
- 2K / 4K 分档缩放（1440 / 1800 / 2200 / 2800 / 3400px 断点对应 1.06 – 1.58），矮屏（≤760px 高）不放大
- 监听 `devicePixelRatio` 变化，窗口拖到 4K 屏时自动重建频谱位图
- 全屏时工具栏自动隐藏，鼠标移近顶部淡入

### ♿ 动效与无障碍
- 统一的动效令牌（`--dur-1…5`、`--ease-std/dec/acc/expo`），一律 decelerate 家族，克制不弹跳
- 尊重系统「减少动态效果」设置（`prefers-reduced-motion`）
- 图标为等线宽 SVG 描边，按钮有 `:focus-visible` 焦点环与 `aria-label`

## 📻 三步开听

1. 点击右上角 **📋 频谱表**，打开电台源编辑器
2. 按下方格式粘贴你的电台源，点 **应用**
3. 点 ▶️ 播放，或点 **自动搜台** 让机器自己找第一个能响的源

> 首次打开没有任何内置电台 —— 这是刻意设计：流地址版权归各广播机构所有，
> 且公开源随时可能失效，所以项目只提供**格式**，不预置**内容**。

## 📋 频谱表 v1 语法

```
// 频谱表 v1 · 电台源清单

分组：央广
CNR 中国之声
  https://example.com/live/zgzs.m3u8
  https://example.com/live/zgzs.mp3
  频率：106.1
  别名：中国之声, 中央一套

上海交通广播
  https://example.com/live/jtgb.m3u8
  频率：105.7
```

挤一行也可以：

```
CNR 中国之声|https://example.com/live/zgzs.m3u8|https://example.com/live/zgzs.mp3
```

| 写法 | 含义 | 简写 |
| --- | --- | --- |
| `分组：xxx` | 分组标题（顶格） | `# xxx` |
| 顶格一行 | 电台名，其下缩进行都归它 | — |
| 缩进两格 + `http(s)://` | 候选源，可写多个，播放时依次尝试 | — |
| `频率：103.9` | 调谐指针精确落到 103.9 | `@103.9` |
| `别名：a, b` | 搜简称也能命中 | `=a, b` |
| `备注：xxx` | 注释，不解析 | `// xxx` |

省略协议头（`live.xxx.com/xxx.m3u8`）会自动补全 `http://`。
搜索框支持台名、别名、频率数字匹配。

## ❓ 常见问题

**为什么打开是空的？**
项目不预置任何电台源。请点「📋 频谱表」按格式录入你自己的源再点「应用」。

**某个源明明能放，却显示 CORS / 网络不通？**
`<audio>` 带 `crossorigin="anonymous"`，跨域策略不通的源加载不了。自动搜台的**静音实播**兜底就是为此设计的；也可以换一个允许跨域的源。

**FM 频率显示 `≈`？**
说明前面四级来源都没命中，用的是按台名哈希的稳定估算值。在频谱表里手写 `频率：` 即可精确。

**全屏后界面变糊？**
全屏缩放走 FLIP + 真实 DOM 缩放，理论上不会糊；若从普通屏拖到 4K 屏，页面会监听 DPR 变化并重建频谱位图，必要时刷新一次即可。

**全屏时工具栏不见了？**
这是设计如此。把鼠标移到屏幕顶部（或触摸屏幕）即可呼出，右上角会出现退出提示。

## 🤝 参与贡献

欢迎提 Issue 与 PR。几个低门槛的切入方向：

- **补电台源**：把你验证可用的源按频谱表格式整理成 `.txt` 提交
- **补 FM 对照表**：`CNR_FM_MAP` 里按城市补频率
- **做新皮肤**：在 `:root` 与 `body[data-skin="xxx"]` 里加一组 CSS 变量，再往 `SKINS` 数组加一项
- **改交互**：动效请复用现有时长 / 缓动令牌，保持沉稳克制的节奏

提交前请确认：单文件仍能独立运行、未引入外部 CDN 依赖、未内置任何第三方流地址。
